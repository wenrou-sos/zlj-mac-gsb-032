# 悦足堂 · 连锁足浴总部门店管理平台

面向连锁足浴品牌的一体化运营系统：**总部统一定价/会员/提成标准 → 门店每日上钟录单 → 交班双签字确认 → 营收自动汇总至总部看板**。零外部运行依赖（Node 内置 HTTP + JSON 文件持久化，图表/签字板均为原生实现）。

## 快速开始

```bash
npm start
# 打开 http://localhost:3000
```

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 总部 | `hq`（或 `boss`） | `123456` |
| 门店 | `s01` ~ `s06`（如 `s01` 外滩店、`s04` 北京国贸店） | `123456` |

其他命令：

```bash
npm run seed          # 重置为内置演示数据（6 店 / 65 技师 / 45 天 5487 笔账单，含完整耗材库存）
node test-e2e.js      # 后端业务流 API 测试（需先 npm start）
node test-inventory.js# 耗材库存核算 API 测试（配方快照/冲正一次/调拨两阶段/盘点报损/分析，需先 npm start）
node test-dom.js      # 总部端页面集成测试（需先 npm i jsdom --no-save 且 npm start）
node test-dom-store.js# 门店端开单→双签字交班集成测试
node test-dom-inventory.js # 耗材库存总部/门店页面集成测试
```

数据存储于 `data/db.json`，删除后重启会自动重新生成种子数据。

## 功能总览

### 总部端
- **品牌经营看板**：全品牌总营收/客单价、会员充值总额（含赠金/卡内余额）、提成总额；各门店营收排行 TOP 榜；品类与项目销售占比环形图；近 7/30/45 天日营收趋势。
- **项目统一定价**：项目目录（时长/价格/品类/上下架），调价后所有门店即时生效；历史账单保留原价不受影响。
- **会员体系**：四级会员（银/金/铂金/至尊）门槛与折扣统一配置；充值满 3000 自动赠 10%，累计充值自动升级。
- **技师提成标准**：四个技师等级默认提成比例（25%~40%）可调；支持「项目 × 等级」专项规则（每单固定金额或自定义比例），优先级高于默认比例，开单时实时计算并展示提成依据。
- **耗材档案与配方**：维护耗材档案（规格/单位/标准采购成本/安全库存/启停）与每个服务项目的标准耗用配方；配方按版本管理，保存即升版本，**只影响之后新开账单，历史账单保留开单当时的配方快照与成本**；统一配置库存不足策略（禁止开单 / 允许负库存并预警）。
- **门店库存总览**：全品牌门店实时库存台账（现存量/在途/移动平均成本/库存货值/低库存与负库存状态）、跨店调拨单全览、未处理库存预警。
- **成本与毛利分析**：耗材耗用成本（净耗用，已扣冲正回补）、采购金额、报损/盘亏/盘盈、期末库存货值；**理论库存 vs 实际库存差异**（按各店最近盘点）；**门店损耗率排行**（(报损+盘亏−盘盈)/理论耗用成本）；**项目毛利分析**（收入−技师提成−耗材成本，含毛利率）。
- **门店管理**：门店档案、新增/编辑。
- **技师档案（全品牌）**：入职登记（培训考核记录、证书、擅长项目多选）、离职、跨店调动；调动记录独立留痕。
- **全品牌流水**：跨店账单流水（含耗材成本、配方版本、冲正状态）、全部门店交班记录、会员充值流水。

### 门店端
- **门店看板**：周期/今日营收、本班次实时收款汇总（现金/刷卡/会员卡/移动支付）、趋势、品类占比、近期交班记录、一键开班；顶部展示**库存待办条**（待确认调入调拨、库存预警快捷入口）。
- **上钟开单**：选择项目（自动带出总部定价）→ 技师（仅本店在职）→ 可选会员（自动折扣并校验卡内余额）；金额、折扣、技师提成、**耗材配方耗用明细/库存缺口/单笔毛利实时试算**；开单成功按当时配方快照自动扣减库存，账单列表支持**冲正**（会员余额退回、耗材仅回补一次）。
- **库存与出入库**：本店库存台账（现存/在途/均价/货值/状态）、**采购入库**（移动平均成本）、**盘点**（自动算盘盈盘亏并调账）、**报损**（计入门店损耗率）、发起跨店调拨、库存预警处理。
- **库存流水**：按类型（采购入库/服务耗用/冲正回补/盘点调整/报损/调出/调入/调拨撤销）、耗材、日期区间查询，含每次变动后的结余与出入库金额合计。
- **调拨处理**：分「待我确认（调入）/我发起的（调出）/全部」三栏；**调出方发起即扣减本店库存转为在途，调入方确认后才正式入对方账**；确认前调出方可途中取消（库存原路回补），已完成不可重复确认、已取消不能再确认。
- **交班结算**：自动生成交班报表（本班接待人数、现金/刷卡/会员卡/移动支付分项、营收与提成合计、技师上钟明细）；**交班人与接班人必须在手写签字板上分别签名**方可完成交班，报表即时同步总部，支持历史回看签名。
- **技师业绩提成**：按日期区间统计每位技师上钟单数、服务时长、营收、应发提成并排名。
- **员工管理**：本店技师入职登记、考核记录追加、擅长项目维护、离职、调动到其他门店。
- **会员管理**：开卡、充值（自动赠金升级）、充值记录查询。

## 关键业务规则
- 提成计算：专项规则（项目+等级，固定额/比例）> 技师等级默认比例；每笔订单落库当时的实付与提成，事后调整标准不改历史数据。
- 会员单只能使用会员卡余额支付，余额不足直接拒绝；折扣按会员等级计算。
- 同一门店同时只允许一个进行中的班次；已交班班次不能再录单、不能重复交班。
- 门店账号只能操作本店数据（技师/会员/班次/账单/库存/调拨均有后端越权校验）。
- 交班签字以 dataURL 图片持久化，双方签名缺一不可。

### 耗材库存核算规则
- **配方快照**：开单成功时把当时配方版本（含各耗材用量与单价）整份写入账单快照并据此扣减；事后总部改配方/改成本只升版本、只影响后续新单，历史账单与已算毛利不变。
- **冲正只回补一次**：账单冲正时按其快照逐耗材回补库存（会员单同时退回卡内余额），账单置「已冲正」；再次冲正被后端拒绝，库存不会二次回补。已冲正账单不计入营收/交班/看板/毛利口径。
- **库存不足策略**（总部统一配置）：`strict` 禁止开单并提示缺口；`negative` 允许扣成负库存继续开单，同时自动产生负库存预警。调拨则无论何种策略都要求可调出库存充足。
- **计价方式**：入库按移动平均成本更新单价；服务耗用、报损、调出按均价核减；盘点盘盈按当前均价入库。
- **跨店调拨两阶段**：调出方发起 → 本店现存立即扣减、数量计入「在途」（流水：调出）→ 调入方确认收货后才入对方账（流水：调入）、调出方在途清零。确认前调出方可**途中取消**（现存原路回补，流水：调拨撤销）。已完成不可重复确认、已取消不可再确认、不可重复取消，后端用单据状态机保证不错账。
- **盘点**：录入实存后自动与账面比对，盘亏出库、盘盈入库并留存盘点单与调整流水，作为「理论库存 vs 实际库存差异」与门店损耗率的核算依据。
- 低于安全库存或出现负库存自动生成预警；补货/回补恢复后自动解除，同店同耗材同类预警不重复堆积。

## 技术结构
```
server/
  index.js   HTTP 服务 + REST API + 鉴权 + 聚合统计（零依赖）
  db.js      JSON 持久化 + 确定性演示数据生成（含耗材/配方/采购/盘点/报损/调拨种子）
public/
  index.html 单页外壳
  css/app.css        品牌主题样式
  js/
    api.js         fetch/token 封装
    ui.js          DOM/弹窗/toast/格式化
    charts.js      纯 SVG 面积图、环形图、排行榜
    signature.js   canvas 手写签字板（鼠标/触摸）
    hq.js          总部视图（技师档案/交班明细等共享函数）
    store.js       门店视图
    inventory.js       总部耗材档案/配方/库存总览/成本毛利分析 + 共享工具
    store-inventory.js 门店库存台账/采购/盘点/报损/流水/调拨
    app.js         登录、布局、哈希路由
```
